# 情绪炼金术 Emotion Alchemy

> 把每一次懊恼，炼成一张有温度的明信片。

## 项目简介

这是一个基于 Vite + React 的中文 Web 应用。
当你感到烦躁、懊恼或学习卡住时，可以在 30 秒内完成一轮荒诞提问，系统会生成一张带时间戳的“懊恼明信片”，并支持收藏、匿名投放和复制分享。

## MVP 功能

- 主页面入口：“我现在很烦 / 懊恼”
- 随机荒诞提问卡：4 个选项 + 自定义输入
- 明信片生成：时间戳、情绪意象、温暖文案、复古卡片样式
- 操作按钮：
  - 💾 收入我的情绪博物馆（localStorage）
  - 🌐 匿名投放到公共情绪墙（localStorage）
  - 📮 发给一个朋友（复制文字到剪贴板）
- 情绪博物馆：网格展示 + 收藏统计 + 点击查看完整明信片
- 公共情绪墙：匿名名 + 时间 + 明信片内容

## 技术栈

- Vite + React
- CSS Modules
- localStorage

## 本地运行

```bash
npm install
npm run dev
```
